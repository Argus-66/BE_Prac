================================================================================
SECTION 8: FEATURE SCALING
================================================================================

scaler = StandardScaler()
scaled_data = scaler.fit_transform(data)

Line Explanation:
- scaler = StandardScaler(): Creates a StandardScaler object
  - StandardScaler normalizes features to have mean=0 and standard deviation=1
  - Formula: (value - mean) / standard_deviation
- scaled_data = scaler.fit_transform(data): Scales the selected features
  - fit(): Calculates mean and standard deviation from the data
  - transform(): Applies the scaling transformation
  - Combined in one operation with fit_transform()
- Why scaling is important for K-Means:
  - K-Means uses distance calculations (Euclidean distance)
  - Features with larger scales dominate the distance calculation
  - Example: SALES (thousands) vs QUANTITYORDERED (tens) without scaling
  - Scaling ensures all features contribute equally to clustering

================================================================================
SECTION 9: FINDING OPTIMAL NUMBER OF CLUSTERS (ELBOW METHOD)
================================================================================

wcss = []
K_range = range(1, 11)

for k in K_range:
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(scaled_data)
    wcss.append(kmeans.inertia_)

Line Explanation:
- wcss = []: Initializes empty list to store WCSS (Within-Cluster Sum of Squares) values
  - WCSS measures how compact clusters are
  - Lower WCSS means tighter, more cohesive clusters
- K_range = range(1, 11): Creates a range from 1 to 10 (testing 1-10 clusters)

- for k in K_range:: Loops through each possible number of clusters
  - kmeans = KMeans(n_clusters=k, random_state=42): Creates K-Means model
    - n_clusters=k: Number of clusters to create
    - random_state=42: Ensures reproducibility
  - kmeans.fit(scaled_data): Fits the model to the scaled data
    - Finds k cluster centers
    - Assigns each data point to nearest cluster
  - wcss.append(kmeans.inertia_): Stores the WCSS value
    - inertia_: Sum of squared distances from points to their cluster centers
    - Lower inertia means better clustering

Purpose: Try different values of K to find the optimal number of clusters

================================================================================
SECTION 10: VISUALIZING THE ELBOW CURVE
================================================================================

plt.figure(figsize=(7,5))
plt.plot(K_range, wcss, marker='o')
plt.title("Elbow Method - Optimal number of clusters")
plt.xlabel("Number of clusters (K)")
plt.ylabel("WCSS")
plt.grid(True)
plt.show()

Line Explanation:
- plt.figure(figsize=(7,5)): Creates a figure with width=7 inches, height=5 inches
- plt.plot(K_range, wcss, marker='o'): Creates a line plot
  - X-axis: K_range (1 to 10 clusters)
  - Y-axis: wcss (Within-Cluster Sum of Squares)
  - marker='o': Adds circle markers at each data point
- plt.title("Elbow Method - Optimal number of clusters"): Sets the plot title
- plt.xlabel("Number of clusters (K)"): Labels the X-axis
- plt.ylabel("WCSS"): Labels the Y-axis
- plt.grid(True): Adds a grid for easier reading
- plt.show(): Displays the plot

Interpretation:
- The plot typically shows WCSS decreasing as K increases
- Look for an "elbow point" where the rate of decrease slows down
- The elbow represents the optimal K (balance between simplicity and goodness of fit)
- After the elbow, adding more clusters doesn't significantly improve clustering

================================================================================
SECTION 11: APPLYING K-MEANS WITH OPTIMAL K
================================================================================

optimal_k = 4
kmeans = KMeans(n_clusters=optimal_k, random_state=42)
cluster_labels = kmeans.fit_predict(scaled_data)

# Add cluster information to original dataframe
df['Cluster'] = cluster_labels

Line Explanation:
- optimal_k = 4: Sets the optimal number of clusters to 4
  - This value was chosen based on the elbow curve visualization
  - Represents a good balance between cluster granularity and simplicity
- kmeans = KMeans(n_clusters=optimal_k, random_state=42): Creates K-Means model with 4 clusters
  - n_clusters=4: Will create 4 distinct customer segments
  - random_state=42: Ensures reproducibility
- cluster_labels = kmeans.fit_predict(scaled_data): Performs clustering
  - fit(): Trains the model and finds 4 cluster centers
  - predict(): Assigns each transaction to nearest cluster
  - Returns array of cluster labels (0, 1, 2, or 3)
- Comment: Explains we're adding cluster assignments back to the original data
- df['Cluster'] = cluster_labels: Adds a new column with cluster assignments
  - Each transaction now has a cluster label indicating which segment it belongs to
