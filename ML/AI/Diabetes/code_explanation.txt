======================================

The goal is to predict whether a patient has diabetes based on various medical features.

  - precision_score: Measures the proportion of positive predictions that are correct
  - recall_score: Measures the proportion of actual positives that were identified

SECTION 7: SPLITTING THE DATASET
================================================================================

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

Line Explanation:
- train_test_split(): Divides the dataset into training and testing sets
  - X, y: The features and target to be split
  - test_size=0.25: Allocates 25% of data for testing and 75% for training
  - random_state=42: Sets a random seed for reproducibility (ensures same split every time the code runs)
  - stratify=y: Ensures that the proportion of classes (diabetes/no diabetes) is maintained in both training and test sets
    - If original data has 65% no-diabetes and 35% diabetes, both train and test sets will have similar proportions
- X_train: Training features (75% of data)
- X_test: Testing features (25% of data)
- y_train: Training labels (75% of data)
- y_test: Testing labels (25% of data)

================================================================================
SECTION 8: TRAINING THE K-NEAREST NEIGHBORS MODEL
================================================================================

knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train, y_train)
knn_pred = knn.predict(X_test)

Line Explanation:
- knn = KNeighborsClassifier(n_neighbors=5): Creates a KNN classifier object
  - n_neighbors=5: Uses 5 nearest neighbors to make predictions
  - The algorithm works by finding the 5 closest training samples to a test sample
  - It then assigns the most common class among those 5 neighbors to the test sample
- knn.fit(X_train, y_train): Trains the model by storing the training data
  - KNN is a lazy learner, so it simply memorizes the training data
  - No complex mathematical model is built; it just stores the data points
- knn_pred = knn.predict(X_test): Makes predictions on the test data
  - For each test sample, finds the 5 nearest training samples
  - Assigns the majority class from those 5 neighbors
  - Stores all predictions in knn_pred

================================================================================
SECTION 10: CALCULATING EVALUATION METRICS
================================================================================

cm = confusion_matrix(y_test, knn_pred)
accuracy = accuracy_score(y_test, knn_pred)
precision = precision_score(y_test, knn_pred)
recall = recall_score(y_test, knn_pred)
error_rate = 1 - accuracy

Line Explanation:
- cm = confusion_matrix(y_test, knn_pred): Creates a confusion matrix
  - Structure: [[True Negatives, False Positives],
                 [False Negatives, True Positives]]
  - True Negatives: Correctly predicted as no diabetes
  - False Positives: Incorrectly predicted as diabetes (but actually no diabetes)
  - False Negatives: Incorrectly predicted as no diabetes (but actually has diabetes)
  - True Positives: Correctly predicted as diabetes

- accuracy = accuracy_score(y_test, knn_pred): Calculates overall accuracy
  - Formula: (Correct Predictions) / (Total Predictions)
  - Formula: (TP + TN) / (TP + TN + FP + FN)
  - Represents the percentage of all predictions that were correct

- precision = precision_score(y_test, knn_pred): Calculates precision
  - Formula: True Positives / (True Positives + False Positives)
  - Answers: "When the model predicts diabetes, how often is it correct?"
  - Important when false positives are costly (e.g., unnecessary treatment)

- recall = recall_score(y_test, knn_pred): Calculates recall (also called sensitivity)
  - Formula: True Positives / (True Positives + False Negatives)
  - Answers: "Of all actual diabetes cases, how many did we catch?"
  - Important when false negatives are costly (e.g., missing a disease diagnosis)

- error_rate = 1 - accuracy: Calculates the error rate
  - The proportion of incorrect predictions
  - If accuracy is 0.75, error rate is 0.25 (25% of predictions are wrong)

Line Explanation:
