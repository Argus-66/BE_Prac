def haversine_vectorized(lat1, lon1, lat2, lon2):
    R = 6371                                       # Radius of Earth in kilometers
    lat1, lon1, lat2, lon2 = map(np.radians, [lat1, lon1, lat2, lon2])   # Convert degrees to radians
    dlat = lat2 - lat1                             # Difference in latitude
    dlon = lon2 - lon1                             # Difference in longitude
    a = np.sin(dlat / 2)**2 + np.cos(lat1) * np.cos(lat2) * np.sin(dlon / 2)**2  # Haversine formula
    return 2 * R * np.arcsin(np.sqrt(a))           # Return distance in kilometers

Line Explanation:
- def haversine_vectorized(lat1, lon1, lat2, lon2):: Defines function to calculate distance
- R = 6371: Earth's radius in kilometers (constant)
- map(np.radians, [lat1, lon1, lat2, lon2]): Converts all coordinates from degrees to radians
  - Trigonometric functions require radians
  - map applies np.radians to all four coordinates
- dlat = lat2 - lat1: Calculates latitude difference
- dlon = lon2 - lon1: Calculates longitude difference
- a = np.sin(dlat / 2)**2 + np.cos(lat1) * np.cos(lat2) * np.sin(dlon / 2)**2: Haversine formula
  - Calculates great-circle distance between two points on a sphere
  - Accounts for Earth's curvature
  - More accurate than simple Euclidean distance for geographic coordinates
- return 2 * R * np.arcsin(np.sqrt(a)): Final distance calculation
  - Returns distance in kilometers
  - _vectorized in name means it works on arrays (not just single values)

print("\n--- Removing Outliers using IQR ---")

def remove_outliers_iqr(df, column, min_value=None):
    Q1 = df[column].quantile(0.25)                  # 25th percentile
    Q3 = df[column].quantile(0.75)                  # 75th percentile
    IQR = Q3 - Q1                                   # Interquartile range (IQR)
    lower = Q1 - 1.5 * IQR                          # Lower bound
    upper = Q3 + 1.5 * IQR                          # Upper bound
    if min_value is not None:                       # If minimum threshold is given
        lower = max(lower, min_value)               # Ensure lower bound is not below logical min
    print(f"{column}: removing outside [{lower:.2f}, {upper:.2f}]")  # Display removal range
    return df[(df[column] >= lower) & (df[column] <= upper)]  # Filter data within range

Line Explanation:
- print statement: Indicates outlier removal process
- def remove_outliers_iqr(df, column, min_value=None):: Defines outlier removal function
  - df: DataFrame to process
  - column: Column name to check for outliers
  - min_value: Optional minimum logical value (e.g., fare can't be negative)
- Q1 = df[column].quantile(0.25): Calculates 25th percentile (first quartile)
  - 25% of data is below this value
- Q3 = df[column].quantile(0.75): Calculates 75th percentile (third quartile)
  - 75% of data is below this value
- IQR = Q3 - Q1: Calculates Interquartile Range
  - Range containing middle 50% of data
  - Measure of statistical dispersion
- lower = Q1 - 1.5 * IQR: Calculates lower outlier threshold
  - Standard IQR method for outlier detection
  - Values below this are considered outliers
- upper = Q3 + 1.5 * IQR: Calculates upper outlier threshold
  - Values above this are considered outliers
- if min_value is not None:: Checks if logical minimum is provided
  - lower = max(lower, min_value): Ensures lower bound makes sense
    - Example: fare_amount shouldn't be negative, so min_value=0
- print(f"{column}: removing outside [{lower:.2f}, {upper:.2f}]"): Shows removal range
- return df[(df[column] >= lower) & (df[column] <= upper)]: Returns filtered DataFrame
  - Keeps only rows where column value is within bounds
  - & is logical AND operator

def evaluate_model(model, X_test, y_test, name):
    y_pred = model.predict(X_test)                         # Predict fares for test data
    r2 = r2_score(y_test, y_pred)                          # Calculate R² (coefficient of determination)
    mae = mean_absolute_error(y_test, y_pred)              # Mean Absolute Error
    mse = mean_squared_error(y_test, y_pred)               # Mean Squared Error
    rmse = np.sqrt(mse)                                    # Root Mean Squared Error
    print(f"\n{name}: R2={r2:.4f}, MAE={mae:.4f}, MSE={mse:.4f}, RMSE={rmse:.4f}")  # Display metrics
    return y_pred, r2, mae, rmse                           # Return results for comparison

Line Explanation:
- Comments: Section header
- def evaluate_model(model, X_test, y_test, name):: Defines evaluation function
  - model: Trained model to evaluate
  - X_test: Test features
  - y_test: Actual test target values
  - name: Model name for display
- y_pred = model.predict(X_test): Makes predictions on test data
- r2 = r2_score(y_test, y_pred): Calculates R² score
  - Measures how well model explains variance in target
  - Range: 0 to 1 (higher is better)
  - 1 = perfect predictions, 0 = no better than mean
- mae = mean_absolute_error(y_test, y_pred): Calculates MAE
  - Average absolute difference between actual and predicted
  - Easy to interpret (in same units as target)
- mse = mean_squared_error(y_test, y_pred): Calculates MSE
  - Average squared difference
  - Penalizes large errors more heavily
- rmse = np.sqrt(mse): Calculates RMSE
  - Square root of MSE
  - Same units as target (more interpretable than MSE)
- print statement: Displays all metrics with 4 decimal places
- return y_pred, r2, mae, rmse: Returns predictions and metrics
