EMAIL SPAM CLASSIFICATION - CODE EXPLANATION
============================================

This notebook implements email spam classification using Support Vector Machine (SVM) and K-Nearest Neighbors (KNN) algorithms.

================================================================================
SECTION 1: IMPORTING LIBRARIES
================================================================================

import pandas as pd
import numpy as np

Line Explanation:
- import pandas as pd: Imports the pandas library and assigns it the alias 'pd'. Pandas is used for data manipulation and analysis, particularly for working with structured data in DataFrames.
- import numpy as np: Imports the numpy library as 'np'. NumPy provides support for large, multi-dimensional arrays and matrices, along with mathematical functions.

================================================================================
SECTION 2: IMPORTING MACHINE LEARNING TOOLS
================================================================================

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix

Line Explanation:
- from sklearn.model_selection import train_test_split: Imports a function to split the dataset into training and testing sets.
- from sklearn.preprocessing import StandardScaler: Imports StandardScaler for feature scaling (normalizing data). Though imported, it's not used in this code.
- from sklearn.neighbors import KNeighborsClassifier: Imports the K-Nearest Neighbors classifier algorithm.
- from sklearn.svm import SVC: Imports Support Vector Classification (SVC), which is the SVM algorithm for classification tasks.
- from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix: Imports various metrics to evaluate model performance.

================================================================================
SECTION 3: LOADING THE DATASET
================================================================================

df = pd.read_csv("emails.csv")

Line Explanation:
- df = pd.read_csv("emails.csv"): Reads the CSV file named "emails.csv" and loads it into a pandas DataFrame called 'df'. This dataset contains email data with word frequency features and spam labels.

print(df.head())

print(df.shape)

df.isnull().sum()

================================================================================
SECTION 5: PREPARING FEATURES AND TARGET VARIABLE
================================================================================

X = df.iloc[:,1:3001]
X

Line Explanation:
- X = df.iloc[:,1:3001]: Extracts the feature matrix X by selecting all rows (:) and columns from index 1 to 3000 (1:3001).
  - These columns contain word frequency features (how often specific words appear in emails)
  - Column 0 is likely an identifier (like Email No.), so it's excluded
  - The dataset has 3000 word features that are used to classify emails
- X: Displays the feature matrix

---

Y = df.iloc[:,-1].values
Y

Line Explanation:
- Y = df.iloc[:,-1].values: Extracts the target variable (labels) by selecting all rows (:) and the last column (-1).
  - The last column contains the spam labels: 1 = spam email, 0 = not spam (legitimate email)
  - .values converts the pandas Series to a NumPy array
- Y: Displays the target labels

================================================================================
SECTION 6: SPLITTING THE DATASET
================================================================================

X_train, X_test, y_train, y_test = train_test_split(X, Y, test_size=0.25, random_state=42)

Line Explanation:
- train_test_split(): Splits the dataset into training and testing sets
  - X, Y: The feature matrix and target labels to be split
  - test_size=0.25: Allocates 25% of the data for testing and 75% for training
  - random_state=42: Sets a random seed for reproducibility (ensures the same split every time)
- X_train: Training features (75% of data)
- X_test: Testing features (25% of data)
- y_train: Training labels (75% of data)
- y_test: Testing labels (25% of data)

================================================================================
SECTION 7: IMPORTING ADDITIONAL EVALUATION METRICS
================================================================================

from sklearn.metrics import classification_report, confusion_matrix

Line Explanation:
- from sklearn.metrics import classification_report, confusion_matrix: 
  - classification_report: Generates a comprehensive report showing precision, recall, f1-score for each class
  - confusion_matrix: Already imported earlier but re-imported here (redundant but harmless)

================================================================================
SECTION 8: SUPPORT VECTOR MACHINE (SVM) MODEL
================================================================================

svc = SVC(C=1.0, kernel='rbf', gamma='auto')
svc.fit(X_train, y_train)
svc_pred = svc.predict(X_test)

Line Explanation:
- svc = SVC(C=1.0, kernel='rbf', gamma='auto'): Creates an SVM classifier with specific parameters
  - C=1.0: Regularization parameter (controls the trade-off between smooth decision boundary and classifying training points correctly)
  - kernel='rbf': Uses Radial Basis Function kernel for non-linear classification
  - gamma='auto': Kernel coefficient (automatically set to 1/n_features)
- svc.fit(X_train, y_train): Trains the SVM model using the training data
- svc_pred = svc.predict(X_test): Makes predictions on the test data and stores them in svc_pred

================================================================================
SECTION 9: SVM MODEL EVALUATION
================================================================================

print("Accuracy:", accuracy_score(y_test, svc_pred))

Line Explanation:
- accuracy_score(y_test, svc_pred): Calculates the accuracy (percentage of correct predictions)
- Formula: (True Positives + True Negatives) / Total Predictions

---

print("Precision:", precision_score(y_test, svc_pred))

Line Explanation:
- precision_score(y_test, svc_pred): Measures the proportion of positive predictions that were actually correct
- Formula: True Positives / (True Positives + False Positives)
- Answers: "Of all emails classified as spam, how many were actually spam?"

---

print("Recall:", recall_score(y_test, svc_pred))

Line Explanation:
- recall_score(y_test, svc_pred): Measures the proportion of actual positive cases that were correctly identified
- Formula: True Positives / (True Positives + False Negatives)
- Answers: "Of all actual spam emails, how many did we correctly identify?"

---

print("F1 Score:", f1_score(y_test, svc_pred))

Line Explanation:
- f1_score(y_test, svc_pred): Harmonic mean of precision and recall (balanced measure)
- Formula: 2 * (Precision * Recall) / (Precision + Recall)
- Useful when you need a balance between precision and recall

---

print("\nConfusion Matrix:\n", confusion_matrix(y_test, svc_pred))

Line Explanation:
- confusion_matrix(y_test, svc_pred): Creates a matrix showing:
  - True Negatives (correctly predicted as not spam)
  - False Positives (incorrectly predicted as spam)
  - False Negatives (incorrectly predicted as not spam)
  - True Positives (correctly predicted as spam)
- \n: Adds a newline for better formatting

---

print("\nClassification Report:\n", classification_report(y_test, svc_pred))

Line Explanation:
- classification_report(y_test, svc_pred): Generates a comprehensive report showing:
  - Precision, recall, and f1-score for each class (spam and not spam)
  - Support (number of samples for each class)
  - Overall accuracy
  - Macro and weighted averages

================================================================================
SECTION 10: K-NEAREST NEIGHBORS (KNN) MODEL
================================================================================

knn = KNeighborsClassifier(n_neighbors=7)
knn.fit(X_train, y_train)
knn_pred = knn.predict(X_test)

Line Explanation:
- knn = KNeighborsClassifier(n_neighbors=7): Creates a KNN classifier
  - n_neighbors=7: Uses 7 nearest neighbors to make predictions
  - The algorithm classifies a sample based on the majority class among its 7 closest neighbors
- knn.fit(X_train, y_train): Trains the KNN model (stores the training data)
- knn_pred = knn.predict(X_test): Makes predictions on test data using the trained KNN model

================================================================================
SECTION 11: KNN MODEL EVALUATION
================================================================================

print("KNN Accuracy:", accuracy_score(y_test, knn_pred))
print("KNN Precision:", precision_score(y_test, knn_pred))
print("KNN Recall:", recall_score(y_test, knn_pred))
print("KNN F1 Score:", f1_score(y_test, knn_pred))
print("\nKNN Confusion Matrix:\n", confusion_matrix(y_test, knn_pred))
print("\nKNN Classification Report:\n", classification_report(y_test, knn_pred))

Line Explanation:
This section calculates and displays all the same evaluation metrics for the KNN model:
- Line 1: Accuracy of KNN predictions
- Line 2: Precision of KNN predictions
- Line 3: Recall of KNN predictions
- Line 4: F1-score of KNN predictions
- Line 5: Confusion matrix showing detailed classification results
- Line 6: Comprehensive classification report with all metrics

All metrics have the same interpretation as explained in Section 9, but now applied to the KNN model's predictions.

================================================================================
SUMMARY
================================================================================

This code demonstrates a comparison between two classification algorithms (SVM and KNN) for email spam detection:

1. Data Loading: Loads email dataset with 3000 word frequency features
2. Data Preparation: Separates features (X) and target labels (Y)
3. Train-Test Split: Divides data into 75% training and 25% testing
4. SVM Model: Trains an SVM classifier with RBF kernel and evaluates performance
5. KNN Model: Trains a KNN classifier with 7 neighbors and evaluates performance
6. Evaluation: Compares both models using accuracy, precision, recall, F1-score, confusion matrix, and classification report

The goal is to identify which algorithm performs better at classifying emails as spam or not spam.
